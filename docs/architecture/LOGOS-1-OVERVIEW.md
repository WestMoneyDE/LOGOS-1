# LOGOS-1 Architecture Overview

## Purpose

LOGOS-1 separates adaptive cognition from authority-bearing assurance and execution. The project is both a falsification program and a path toward coding-ready agent architecture.

## Layer model

1. **Observation / external evidence** — inputs with provenance.
2. **Adaptive cognition** — learned memory, reasoning, world models and evaluation.
3. **Proposal interface** — typed candidate actions/decisions.
4. **Γ / assurance boundary** — non-learning authority, policy, occurrence binding and reconciliation.
5. **Executor / world** — real effects and their externally grounded outcomes.

## Non-negotiable separations

- cognition ≠ execution;
- memory ≠ assurance state;
- epistemic confidence ≠ permission;
- correct enforcement ≠ correct specification;
- external-effect ambiguity ≠ evidence of non-execution.

## Scientific status vs implementation target

A component appearing in an engineering diagram is not automatically a promoted scientific primitive. LOGOS keeps:

- **research verdicts** in evidence/session artifacts;
- **engineering targets** in architecture documents;
- **operational truth** in code, tests and external returns.

When these disagree, executable evidence and accepted current decisions override stale prose.
